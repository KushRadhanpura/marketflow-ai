# MarketFlow AI Frontend

Next.js dashboard for the MarketFlow AI MVP.

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Test
```bash
npm test
```

## Notes
- The app uses the backend API at `NEXT_PUBLIC_API_URL`.
- The current UI includes the landing page, dashboard, campaign list, campaign creation wizard, and campaign detail tabs.
- Recharts is used for dashboard charts.
